# Bible Study — iOS & Android App

A Bible study app for the iOS App Store and Google Play, built by wrapping the
existing Bible study web app with [Capacitor](https://capacitorjs.com/).

**What it is:** King James Bible reader (all 66 books, 31,102 verses), tap-a-word
Webster's 1828 definitions, word study, reference + phrase search, verse of the
day, **Prayer of the Day** (a short daily prayer), **Learn to Pray** (a Pray tab
teaching the ACTS pattern, the Lord's Prayer as a pattern, and praying
Scripture), notes & favorites (saved on device), e-Sword info, Places (photos + maps),
12 BibleProject videos, and a Fun tab with free Bible games, the Bible
Mysteries Podcast, and a **"Places to Go" map of 12 verified Christian-themed
family attractions** (Ark Encounter, Creation Museum, Museum of the Bible,
Sight & Sound, Billy Graham Library, and more — map pins + an offline list).

**Price: free.** The app is free to download, with no paywall and no
in-app purchases — every part of it is free to use. The only donation option
is a voluntary Ko-fi button ("Support the Bible Study"); gifts are never
required, and proceeds go to charity (the specific charity is to be named by
the owner).

**What it is NOT:** this is a standalone Bible study app. It does not link to
Rick Demers' SRM training site, and it does not include the Panama City
Beach local fun venues (those stay on the website only).

## Build the Android app (debug APK, for trying it out)

Prerequisites: JDK 17 and the Android SDK (see below).

```bash
cd bible-study-app
npx cap sync          # copy www/ into android/ + ios/
cd android
./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Install the APK on an Android phone by copying it over and tapping it
(allow "Install unknown apps" for your file/browser app when asked), or:

```bash
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

### Android SDK setup (Linux)

```bash
sudo apt-get install -y openjdk-17-jdk
# Download Android command-line tools from
# https://developer.android.com/studio#command-line-tools-only
# Unzip to $HOME/Android/Sdk/cmdline-tools/latest, then:
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
```

## Build the iOS app

An iOS `.ipa` **cannot** be built on Linux — it needs Xcode on a Mac.
The `ios/` folder in this project is a complete, ready Xcode project.

### Option A — a Mac with Xcode (simplest for one person)

1. Get an Apple Developer account ($99/year) at
   https://developer.apple.com/programs/enroll/ (sign in with your Apple ID).
2. On the Mac, open `ios/App/App.xcworkspace` in Xcode.
3. In Xcode: select the App target → Signing & Capabilities → pick your
   Team (your Apple Developer account) and make sure the Bundle ID is
   `com.rickdemers.biblestudy`.
4. Connect your iPhone and run it (for trying it out), or
   Product → Archive, then Distribute App → App Store Connect (for TestFlight
   / publishing).

### Option B — cloud build (no Mac needed)

The included GitHub Actions workflow (`.github/workflows/build.yml`) builds
the Android APK on every push, and builds the iOS app on a macOS runner.
For a signed iOS build (TestFlight / App Store), add these repository secrets
and the workflow will produce a signed `.ipa`:

- `APPLE_CERT_P12_BASE64` — your Apple distribution certificate (.p12), base64
- `APPLE_CERT_PASSWORD` — the .p12 password
- `APPLE_PROVISIONING_PROFILE_BASE64` — the App Store provisioning profile
- `APPLE_TEAM_ID`, `APPLE_ID`, `APPLE_APP_PASSWORD` — for uploading to
  App Store Connect (or use Codemagic: https://codemagic.io — connect the repo,
  pick iOS, add the same credentials, and it builds + ships to TestFlight).

## Trying it before publishing (required by the owner)

- **Android:** install the debug APK from this repo (see above) and use the app.
- **iOS:** use TestFlight. Once the app is archived and uploaded to App Store
  Connect, add yourself as a tester in App Store Connect → TestFlight and
  install it from the TestFlight app. Nothing is published to the public store
  until the owner approves it.

  Fun tab online games, Bible Mysteries Podcast (free public site), e-Sword,
